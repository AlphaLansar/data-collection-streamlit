# 1. Présentation du projet

Ce projet consiste à concevoir une chaîne complète de collecte et d'analyse de données à partir de sources web.

L'objectif est de mettre en place une plateforme permettant :

- la collecte automatique de données web ;
- le nettoyage et la préparation des données ;
- le stockage dans une base de données SQL ;
- l'analyse exploratoire ;
- la visualisation interactive ;
- l'évaluation de l'application par des utilisateurs.
